# Code of Conduct

We want Min Infograph to be a welcoming, respectful project for people with different backgrounds and levels of experience.

Be considerate, use inclusive language, give feedback about work rather than people, and accept constructive criticism. Harassment, discrimination, personal attacks, and publishing private information without permission are not acceptable.

Project maintainers may remove comments, edit contributions, or restrict participation when conduct harms the community. To report an issue, contact the maintainers through the organization’s GitHub contact channels.
