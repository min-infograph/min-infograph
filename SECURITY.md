# Security Policy

Please do not report security vulnerabilities in public issues.

Report a suspected vulnerability through GitHub’s private vulnerability reporting for the affected repository. Include the affected version or commit, steps to reproduce, and the impact you observed. The maintainers will acknowledge reports and coordinate a fix and disclosure.

Min Infograph validates document structure and local image paths, but Mermaid diagram strings are passed to Mermaid for client-side rendering. Keep Mermaid and other dependencies up to date and do not treat untrusted authored diagrams as a security boundary.
